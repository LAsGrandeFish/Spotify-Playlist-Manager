Project: Spotify Playlist Manager

Project Type:
Full-stack playlist review and cleanup web application

Project Summary:
Spotify Playlist Manager is a keyboard-centric web app for reviewing large Spotify libraries and batching playlist decisions before one confirm step. Users can inspect playlists, review tracks quickly, queue keep/remove/add actions, create new target playlists during review, and then apply the resulting Spotify mutations in one controlled workflow.

Core Stack:
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Spotify OAuth + Web API + Web Playback SDK

Current Product State:
- Left rail loads all playlists plus `Liked Songs`
- Viewer mode shows playlist hero, track table, metadata, and incremental loading
- Review mode supports keep/remove/undo, playlist targeting, new playlist targets, playback controls, and resumable review sessions
- Summary mode shows removed / kept / added groups, confirm status, retry support, and confirm-attempt history
- Confirm flow applies real Spotify writes for removals, playlist additions, liked-song removals, and review-created playlists

Core Features:
- Keyboard-driven playlist review workflow
- Multi-stage viewer -> review -> summary product flow
- Persistent review sessions with resume support
- Batch confirm pipeline with chunked Spotify API writes
- Partial-failure diagnostics and retry support
- Post-confirm reconciliation against refreshed Spotify data
- Playback support inside review mode

Implementation Details:
- The app stores review sessions, track actions, add targets, and confirm attempts in Prisma-backed tables
- Spotify token refresh and stale-session handling are built into the auth/session layer
- Confirm logic is failure-aware and avoids replaying successful work when retrying
- Duplicate-add behavior is guarded so tracks are not re-added to target playlists by default
- UI state and Spotify writes are coordinated through typed client/server flows

Environment Note:
The Postgres password contains a `$`, so `DATABASE_URL` should use URL encoding for that character.

Example:
`DATABASE_URL="postgresql://postgres:VUu%24MjU0E@localhost:5432/spotify_playlist_manager?schema=public"`
